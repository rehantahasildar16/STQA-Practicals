STQA PRACTICALS - AUTOMATIC PYTHON LIBRARY INSTALLER

HOW TO USE
1. Extract this ZIP file.
2. Keep requirements.txt and install_requirements.bat in the same folder.
3. Make sure Python is already installed and internet is available.
4. Double-click install_requirements.bat.
5. Wait until the installer says ALL PYTHON LIBRARIES INSTALLED.

Included Python packages:
- selenium 4.45.0
- openpyxl
- pytest
- pytest-html
- locust

Built-in Python modules such as time, os, logging and unittest do not need installation.

IMPORTANT
This installer installs Python packages only. It does NOT install:
- Python itself
- Google Chrome / Firefox / Edge
- Java JDK
- Selenium Server JAR
- Jenkins
- Microsoft Excel

Selenium Manager (included with modern Selenium) can manage browser drivers
automatically in supported environments, but the browser itself must be installed.

The practical document specifies Python 3.14 for several practicals and Windows 10/11
for Selenium Grid. Older Windows versions may not support current Python/package
versions. Use a supported Windows version and a compatible Python installation.
